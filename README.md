# CampusConnect — Online Campus Club & Activity Portal

A responsive front-end mini project for the Web Essentials subject. CampusConnect helps students discover campus clubs, explore events, search/filter activities, and manage their event registrations.

## Features
- Responsive home page and navigation
- Campus club directory
- Upcoming events listing
- Search events by name, club, venue, or category
- Category filter
- Register/cancel event participation
- “My Registrations” section
- Browser LocalStorage saves registration choices

## Tech Stack
- HTML5
- CSS3
- JavaScript
- LocalStorage (browser-side storage)

## Run locally
1. Download or clone the repository.
2. Open `index.html` in a web browser.

## GitHub Pages
In the repository, go to **Settings → Pages**. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save. The site URL will be `https://YOUR-USERNAME.github.io/CampusConnect/`.

## Project purpose
This is a student mini project demonstrating front-end web design, event filtering, interaction, and browser-side data persistence.
